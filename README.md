Sunset Estates

Agency demo of a cinematic listing film: scroll-scrubbed stills (Seedance clips when Higgsfield is connected), overlay facts, showing form, gallery. Not WebGL.

This folder is the build-out to show agencies. For a real client, swap `src/listing.json`, `public/stills/`, and `public/film/` — do not ship this listing’s photos as a public site.

```powershell
cd "$env:USERPROFILE\Projects\sunset-estates"
npm install
npm run dev
```
